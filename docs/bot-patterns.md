# Bot 部署模式调研（2026-10-17）

看了 B站 上的私信机器人教程、GitHub 上的 Bilibili 私信 bot，以及 DSH 生态里成熟的消息网关。
结论：**成熟的 bot 都不是「每条消息都叫醒模型」**，而是「预制回复 → 关键词闸门 → 才轮到模型」。

## 参考

| 项目 | 关键做法 |
|---|---|
| [Bilibili_PrivateMessage_Bot](https://github.com/7Hello80/Bilibili_PrivateMessage_Bot)（B站教程 BV1c2WxznEsJ） | 关键词规则多条匹配、回复里自动 @ 对方、自动回关、多账号、Web 面板、轮询私信 |
| [dsh-message-gateway](https://github.com/a792883583/dsh-message-gateway) | 每聊天独立 agent 会话、流式回复、上下文自动压缩、按「平台+关键词前缀」路由到不同预设、凭据 600 权限原子写、日志脱敏、**绝不静默丢弃**、会话数上限淘汰最旧 |
| BiliBot（BV1coreBqEko） | 托管式（无需自部署），本质也是规则 + 模板 |

## 五条通用模式

1. **三级触发阶梯**
   - 一级：**预制回复**（精确/前缀/正则）→ 立即回，0 token
   - 二级：**关键词 + 发件人白名单** → 叫醒模型
   - 三级：其余 → 只记录（或每天一次「收到」兜底）
2. **按聊天隔离会话**
   每个联系人一个会话，带自己的上下文；会话数有上限，超了淘汰最旧（gateway 默认 40）。
3. **命令面**
   `/help` `/status` `/time` 这类固定命令走模板，不进模型；中文别名同理。
4. **安全与运维**
   凭据独立文件、权限 600、原子写、接口永不回传明文、日志脱敏；回复频率与每日上限硬编码。
5. **绝不静默丢弃**
   不支持的/没匹配的消息，要么给一条可见模板，要么明确记「已收到，不回」；不能让人「发了消息却毫无响应」。

## 套到 autowhale 上

```
收到私信/回复
  ├─ 去重（msg_seqno / rpid）
  ├─ 预制规则命中？ → 立刻回模板（含 @、时间），记 contact_events，0 token
  ├─ 发件人在白名单？或命中关键词？ → 叫醒一轮 headless（带 prompts/inbox.md）
  │     └─ 模型读这一条 → 回一条 / 或判定不回 → 写 contact_events
  └─ 其它 → 记录，不叫醒
```

### 预制回复示例（`config/replies.json`）

| 匹配 | 动作 |
|---|---|
| `在吗` / `在不在` | 模板：「在。本鲸在值班，有事直接说。」 |
| `/status` | 插件状态模板（跑了没、额度、未读） |
| `/help` | 命令列表 |
| `帮我` / `报错` / `失败` / `bug` | 走模型 |
| `抽奖` / `互关` / `广告` | 忽略 |

### 防封号

- 私信在对方回复前只能发 1 条（21047）——预制回复不能绕过这条，别硬发
- 每天主动 ≤3 条、同一人 7 天冷却、同一段话不群发、首条不带链接
- 不做自动回关、不做批量关注（BPMB 有这功能，但我们不需要）

## 对 watcher 的修正

原方案「命中就 spawn 一轮」改成：

1. **先查 canned 规则**（宿主侧，纯字符串匹配）
2. canned 命中 → 直接调 B站 私信接口回复，**不 spawn**
3. 只有 `action: llm` 或白名单长消息才 spawn；spawn 时把「会话里最近 3 条」一起带上，避免断章取义
4. 每联系人一个 `last_seqno`，同一会话多消息合并成一次唤醒（debounce 20s）

## 价值分闸门（已实现）

`config/gate.json` 定义权重，`scripts/score-message.mjs` 先跑预制回复、再打分：

| 信号 | 分值 |
|---|---|
| 主人 / 白名单 / 见过的熟人 | +4 / +3 / +1 |
| 疑问句 | +2 |
| 任务词（帮我/看看/修/部署/报错/bug…） | +2 |
| 具体信息（BV 号 / 链接 / 数字 / 日志 / token） | +2 |
| 长消息（≥30 字） | +1 |
| 极短（≤3 字） | -1 |
| 广告词（互关/抽奖/广告…） | -5 |

决策（**浅过滤**）：`score ≥ 4` 就走 llm；`2–3` 发模板；`< 2` 忽略。
≤4 字的纯短句（如 `1+1`）即使来自白名单也**不叫模型**——只挡琐事，不挡正常对话。

实测：

| 发件人 | 消息 | 分数 | 决策 |
|---|---|---|---|
| 一只深沉 | `1+1` | 4 | ignore（短句规则） |
| 一只深沉 | `在吗` | 5 | canned（「在。本鲸在值班…」） |
| 一只深沉 | `帮我看看这个报错` | 7 | llm |
| 一只深沉 | `这没关系。我接下来会在这里较多地向你通信` | 5 | llm |
| 陌生人 | `1+1` | -1 | ignore |
| 陌生人 | `请问这个插件怎么配置` | 2 | template（「收到，这条我记下了」） |

核心：**浅过滤**——熟人只要不是寒暄/纯短句就直接进模型；陌生人只给模板，不白烧 token。
